# Active Directory User Correlation

# Description
Managed identifiers for AD Users and discover users with conflicting entries

# Prerequisites
- [Standard Item Library](https://github.com/Tools4ever-NIM/NIM-Framework-ItemLibrary)

# Installation
- Download app.json source file
- Within NIM
- 	Go to Apps
- 	Click Import
- 	Select app.json
-	Create each missing audit query
- 	Complete Import
- 	Under Apps, Uncheck "Exportable" if checked
